# Nature Quest 3D

Explore a tiny 3D nature world, visit the forest, ocean, and wildlife habitats, and answer quiz questions to earn points.

## Run locally
You need an internet connection to load Three.js from the CDN. From the repository root run:

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000>. Move with **WASD** or **arrow keys**; press **E** near a glowing habitat to start its quiz. This prototype uses Three.js from jsDelivr and needs a browser with WebGL support.
